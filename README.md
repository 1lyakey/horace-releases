# Horace — releases

Установщики Horace для Windows. Код приложения живёт в приватном репозитории; здесь — только готовые сборки,
чтобы приложение могло обновляться само (`latest.json` в каждом релизе).

- `Horace-Setup-<версия>.exe` — установщик (для текущего пользователя, без прав администратора)
- `Horace-Portable-<версия>.exe` — без установки
- `latest.json` — манифест для автообновления

Беты помечены как pre-release.
